# Contributors and attribution

Barebuh is a modified fork of Strawberry Music Player, which was forked from
Clementine. Git history and existing file headers are the authoritative
per-change attribution record.

The Strawberry author and contributor lists are retained in the About dialog,
and Clementine attribution remains in inherited source files and UI credits.
[`debian/copyright`](debian/copyright) records the repository's mixed copyright
and compatible-license inventory. Those notices must not be replaced by a
blanket “Barebuh contributors” claim.

New Barebuh-authored files use:

```text
Copyright 2026 Barebuh contributors
SPDX-License-Identifier: GPL-3.0-or-later
```

Use a personal or organizational copyright line instead when that is the
actual rights holder. Never add a contributor without their consent, and never
infer legal identity from a forge username or local Git configuration.

The public maintainer, publisher, and legal-contact identities are unresolved.
This file intentionally contains no guessed names or contact coordinates.
